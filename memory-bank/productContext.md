# Product Context

**Why this project exists:**
Basket Club Manager was created to provide a dedicated, mobile-first management experience for basketball club administrators and coaches. It allows them to track all critical club activities and data in one place.

**Core Experience:**
The application is designed to be an **offline-first** solution. It runs on both iOS and Android devices, storing all user and club data locally on the device using an SQLite database. This ensures that the app is fast, responsive, and available even without an internet connection, which is crucial for on-the-go management during games or training sessions.
