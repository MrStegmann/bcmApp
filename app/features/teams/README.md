# Feature template

Copia esta carpeta para crear una nueva feature.

## Ejemplo de uso

1. Duplicar `_feature-template`.
2. Renombrar a `clubs`.
3. Completar carpetas y archivos.

Resultado:

- `features/clubs/components/ClubCard.jsx`
- `features/clubs/screens/ClubListScreen.jsx`
- `features/clubs/api/clubApi.js`
- `features/clubs/store/clubStore.js`
