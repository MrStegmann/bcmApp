# Feature Exercises

Copia esta carpeta para crear una nueva feature.

## Ejemplo de uso

1. Duplicar `_feature-template`.
2. Renombrar a `exercises`.
3. Completar carpetas y archivos.

Resultado:

- `features/exercises/components/ExerciseCard.jsx`
- `features/exercises/screens/ExerciseListScreen.jsx`
- `features/exercises/api/exerciseApi.js`
- `features/exercises/store/exerciseStore.js`
