## Summary

The `Match Detail View` provides a comprehensive post-game inspection and analytics interface for finished basketball matches. The view renders:
1. Cumulative final score and a quarter-by-quarter breakdown of points and fouls for both teams.
2. A match roster sorted descending by player Valuation (`Value`), where each player is an interactive button revealing their complete box score upon tap.
3. Advanced team efficiency statistics (Possessions, OER, DER, eFG%, ORB%, AST%, TOV%, FTR) paired with an 8-axis polygon/radar chart visualizer.
4. An Edit Mode allowing scorekeepers or coaches to adjust period scores, period fouls, and player individual statistics with immediate persistence and automatic recalculation of all dependent metrics.

The feature is built following the application's Constitution: self-contained domain feature module (`src/features/match-detail/`), TDD with Jest and React Native Testing Library, Drizzle ORM with SQLite persistence, Zustand state management, and NativeWind utility styling.

**Language/Version**: TypeScript 5.9+ / React Native 0.86.3 / React 19.2.3 / Expo SDK 57  
**Primary Dependencies**: React Native, NativeWind v4, Tailwind CSS v3.4, Zustand v5, Drizzle ORM v0.45, `expo-sqlite` v57, `react-native-svg` (for 8-axis polygon radar chart)  
**Storage**: SQLite (`bcmapp.db`) accessed via `expo-sqlite` and `drizzle-orm`  
**Testing**: Jest v29 + `@testing-library/react-native` (TDD red-green-refactor)  
**Target Platform**: Mobile (Android & iOS via Expo managed workflow)  
**Project Type**: Mobile Application (React Native / Expo)  
**Performance Goals**: < 1s screen transition from match list, < 50ms tactical math recalculation, 60fps smooth scrolling across all viewport sizes  
**Constraints**: 100% offline-capable local persistence, zero division-by-zero crashes or `NaN` displays, responsive layout across phones and tablets  
**Scale/Scope**: 1 primary feature container (`MatchDetailView`), 7 focused subcomponents, 1 Zustand store, 1 pure calculations engine, 1 geometry helper
