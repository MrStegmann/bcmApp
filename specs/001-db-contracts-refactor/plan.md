# Implementation Plan: Database & Contracts Refactor

**Branch**: `001-db-contracts-refactor` | **Date**: 2026-09-27 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/001-db-contracts-refactor/spec.md`

## Summary

Refactor local database architecture by defining type-safe relational schemas using **Drizzle ORM** and **Expo SQLite**, establishing clear foreign key cascades across Teams, Players, Games, PlayerStats, Trainings, TrainingPlayers, and Fees. Migrate all database connection logic, contracts, entity models, controllers, Zustand stores, and custom hooks from JavaScript to strict **TypeScript**, eliminating missing import crashes and runtime fetch errors across UI views.

## Technical Context

**Language/Version**: TypeScript 5.x (Strict Mode enabled) / React Native 0.86.3  
**Primary Dependencies**: Expo (~57.0.25), Expo SQLite (`expo-sqlite`), Drizzle ORM (`drizzle-orm`), Zustand (`zustand` ^5.0.8), NativeWind (`nativewind` ^4.2.1)  
**Storage**: Local relational SQLite database via `expo-sqlite` and `drizzle-orm`  
**Testing**: Jest test runner (`jest`), `@testing-library/react-native`  
**Target Platform**: Mobile (iOS & Android via Expo managed workflow)  
**Project Type**: Mobile Application  
**Performance Goals**: Database queries complete in <50ms; 60fps UI rendering  
**Constraints**: 100% offline capability; compile-time type safety; strict TDD first  
**Scale/Scope**: 7 relational tables, 6 core UI views, full JS to TS contract migration
